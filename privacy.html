Privacy policy

AI Digest Sync — last updated 22 October 2026

Scope

AI Digest Sync is a personal, single-user application used by its owner only. This policy describes what it does with data. Because the application is not offered to the public and has no other users, no personal data belonging to anyone else is collected, processed, or stored.

What the application accesses

  • Google Drive, with the https://www.googleapis.com/auth/drive scope. This access is used solely to create and update the daily digest files in a folder chosen by the account owner.
  • Public RSS feeds. These are ordinary web requests; no account or personal information is sent with them.

What is stored, and where

  • The OAuth credentials issued by Google are stored in a configuration file on the owner's own private server. They are not transmitted anywhere else.
  • The generated digests are stored on that server and in the owner's own Google Drive folder.
  • Nothing is stored on any third-party server, and no data is sold, rented, or shared.

What is not done

  • No data is shared with third parties.
  • No data is used for advertising, profiling, or training machine-learning models.
  • No data is transferred to any party other than Google itself, which is necessary for the application to save files to the owner's Drive.
  • No human other than the account owner can read the data.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Digest files are kept in Google Drive for a short rolling window and deleted automatically afterwards.
  • Revoking the application's access in the Google account settings removes its ability to access Drive immediately. The owner can also delete the stored credentials on the server at any time.
  • Because only the owner's own data is involved, no third-party deletion request process is necessary.

Changes

If this policy changes, the revision date at the top of this page will be updated.

Contact

This application is personal software, not a service. For any question about it, contact its owner.
