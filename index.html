AI Digest Sync

A personal tool for collecting AI news and saving daily digests to Google Drive.

What it is

AI Digest Sync is a private, single-user utility. It runs on my own server and does one thing: it gathers headlines from a fixed list of public RSS feeds about artificial intelligence, arranges them into a daily Markdown digest, and uploads that file into a folder in my own Google Drive.

How it uses your Google account

  • It signs in to Google with the drive scope, which lets it create and update the digest files it produces.
  • It writes only to the folder I choose. It does not read, modify, or delete any other file in the account.
  • The sign-in is granted once by the account owner. There is no third-party service in the middle: the tool talks directly to Google's API.
  • Access can be revoked at any time from myaccount.google.com/permissions.

Who can use it

This application is for personal use only. It is not distributed, not listed in any directory, and not offered as a service to the public. It is used by fewer than 100 accounts — in practice, by one.

Data

  • No analytics, no tracking, no advertising, no accounts to register.
  • The digest content is compiled from publicly available RSS feeds.
  • Google credentials are stored only on the owner's own server.
